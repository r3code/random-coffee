# CHANGELOG

Все заметные изменения в проекте Random Coffee Cards документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [4.3.0] — 2026-09-17

### Добавлено
- **Кэш-стратегия `NetworkFirst` для HTML** с таймаутом 3 секунды: при наличии интернета браузер сначала спрашивает сервер, есть ли свежий `index.html`, и берёт его. Если сеть медленная или отсутствует — fallback на кэш SW. Решает проблему «у одного пользователя старая версия, у другого новая» — оба игрока с интернетом получают актуальный HTML, который подключает актуальные ассеты (с хешем в имени файла).
- **`StaleWhileRevalidate` для ассетов** (JS/CSS/иконки): быстро из кэша, в фоне проверяем свежую версию. Имена файлов с хешем — при изменении содержимого URL меняется, кэш-мисс → свежая версия.
- **UI уведомления об обновлении** через `useRegisterSW` (`virtual:pwa-register/vue`): при обнаружении новой версии SW показывается баннер «🔄 Доступна новая версия» с кнопкой «Обновить». `registerType: 'prompt'` — пользователь сам решает, когда перезагрузить, без авто-обновления в середине сессии.
- **Баннер «Готово к оффлайн»** при первом кэшировании SW — пользователь видит, что приложение можно запускать без интернета.
- В `workbox` конфигурации: `runtimeCaching` с двумя стратегиями, `navigateFallback: 'index.html'`, expiration rules (HTML — 7 дней/5 записей, ассеты — 30 дней/60 записей).

### Изменено
- `vite.config.js` — добавлен `workbox.runtimeCaching` с `NetworkFirst` (HTML) и `StaleWhileRevalidate` (ассеты).
- `src/App.vue` — добавлены `useRegisterSW`, баннеры `needRefresh` и `offlineReady`, кнопки «Обновить» и «Позже».

## [4.2.0] — 2026-09-17

### Добавлено
- Кнопка «Установить приложение» для Android/Desktop Chrome — перехватывает `beforeinstallprompt`, показывает подсказку с кнопкой «Установить». После установки — баннер «Приложение установлено» на 4 секунды.
- На iOS Safari — текстовая инструкция «Нажмите Поделиться → На главный экран» (Apple не даёт программно вызвать установку).
- Запоминание отказа: если пользователь отклонил подсказку (крестик или системный диалог), не показываем снова до ручного сброса `localStorage['install_dismissed']`.
- Не показывается в standalone-режиме (PWA уже установлено и открыто с иконки) — через `matchMedia('(display-mode: standalone)')` и `navigator.standalone` (iOS).
- Компонент `src/components/InstallPrompt.vue`, подключён в `App.vue`.

## [4.1.0] — 2026-09-17

### Добавлено
- Лимит на количество хранимых сессий: не более 20 последних. При превышении самые старые (по `updatedAt`) удаляются, но активная и только что добавленная защищены от авто-удаления.
- Надпись в блоке истории: «Хранится не более 20 последних сессий».
- Экспорт конкретной сессии по её id — кнопка ↓ в каждой карточке истории. Имя файла: `coffee-cards-<deckId>-<orderLetter>-<YYYY-MM-DD>.json`.
- Импорт сессии из файла — кнопка «📥 Импорт сессии из файла» внизу блока истории.
- Подсветка новой импортированной записи на 2 секунды (зелёная рамка + фон).
- `title` на всех иконочных кнопках истории для подсказки при наведении.
- CHANGELOG.md по формату Keep a Changelog (русский).
- Версия приложения и хеш коммита в footer на главном экране, ссылка на GitHub.

### Изменено
- «Активна» — больше не disabled-кнопка, а бейдж `<span>● Активна</span>` без рамки/фона. Визуально отличается от интерактивных кнопок.
- Удаление — `🗑️` (эмодзи) заменено на `✕` (чистый знак, привычный для закрытия/удаления).
- Экспорт — `⬇️` (эмодзи) заменено на `↓` (простая стрелка без обвязки).
- Утилитарные кнопки (↓, ✕) — квадратные `w-9 h-9`, приглушённый фон `bg-gray-700/60`. ✕ на hover становится красным — визуальная подсказка, что это опасное действие.

### Исправлено
- Баг «вопрос 16 из 15» — `migrateV1ToV2` теперь вычисляет `completed` на основе `currentTurn >= sequence.length`, а не пишет `completed: false` всегда.
- `loadSession` больше не портит целевую сессию при переключении — добавлен флаг `isLoading` и `persistActiveSession()` для атомарной записи.
- `hasSavedSession` — defensive check: `false` если `currentTurn >= sequence.length`, даже если `completed: false` из-за старого бага.

### Удалено
- Глобальные кнопки «Экспорт состояния» / «Импорт состояния» над историей — дублировали функции в карточках. Заменены на экспорт у каждой сессии и импорт внизу истории.
- `exportState()` в UI больше не используется (оставлен только для обратной совместимости и тестов — вызывает `exportSession(activeSessionId.value)`).

## [4.0.0] — 2026-09-17

### Добавлено
- Новая структура кнопок в GameView: основная кнопка («Партнёр ответил» / «Я ответил») отдельной строкой под контентом, не в одном flex-ряду с навигационными.
- Footer отдельно — для навигационных кнопок «← Предыдущий», «⏭️ Пропустить», «Следующий →».
- `min-height: 35vh` для main — фиксирует высоту, основная кнопка не прыгает при смене карточки на 🤔 и обратно.
- Кнопки разных цветов: «Партнёр ответил» — жёлтая (`bg-yellow-500`), «Я ответил» — зелёная (`bg-emerald-500`). Пользователь мгновенно видит по цвету, в каком он режиме.
- Различение светлая/тёмная тема в GameView:
  - Читающий — индиго фон (`bg-indigo-100` светлая / `bg-indigo-950` тёмная)
  - Отвечающий — изумруд фон (`bg-emerald-100` светлая / `bg-emerald-950` тёмная)
- Кнопка «Следующий →» — видна если следующий ход в пределах `maxReachedTurn` (мы туда уже доходили). Использует новое действие `nextTurn()` — переход без модификации `passedIds` / `skippedIds`.
- `maxReachedTurn` — новый ref, отслеживает максимальный достигнутый ход в текущей сессии. Сохраняется в localStorage, восстанавливается при перезагрузке.
- `isJumpedTurn` — текущий ход был перепрыгнут skip'ом. Условие: `currentTurn < maxReachedTurn` И текущий вопрос не в `passedIds` / `skippedIds`.
- Экран перепрыгнутого хода: компактный заголовок «⏭️ Этот ход был пропущен» + объяснение «Читающий пропустил этот вопрос — партнёр не услышал его, поэтому и отвечать не на что. Переходи к следующему ходу кнопкой «Следующий →» внизу.»
- На перепрыгнутом ходу нет основной кнопки и «⏭️ Пропустить» — только «← Предыдущий» и «Следующий →».
- Защита от дублей: `nextQuestion` не добавляет id в `passedIds`, если уже там; `skipQuestion` не добавляет в `skippedIds`, если уже там.
- 13 новых тестов Vitest (всего 85): nextTurn, isJumpedTurn, isNextOpened, защита от дублей, миграция завершённой v1.

### Изменено
- «← Назад» в шапке GameView → «← На главную» — однозначно показывает, что кнопка ведёт на главный экран.
- Keyboard nav в GameView: ← / → работают всегда (навигация), Enter / S только у читающего на не-перепрыгнутом ходу.

## [3.0.0] — 2026-09-17

### Добавлено
- Новая логика ролей:
  - **Читающий** видит карточку с вопросом и нажимает «Партнёр ответил».
  - **Отвечающий** НЕ видит карточку (только 🤔 + подсказку) и нажимает «Я ответил».
  - Роли чередуются после каждого вопроса.
- Skip = пропуск всего раунда: `currentTurn += 2`. Если читающий пропустил вопрос, партнёр не услышал его — отвечать нечего, переходим к следующему «читающему» ходу.
- Тексты на «ты» форму вместо казённого «вы».
- Названия ролей: «Я читаю первым» / «Я слушаю первым» (вместо «Начну с чтения» / «Начну со слушания»).
- Инверсия роли в share-ссылке: если я reader, партнёр откроет ссылку с `role=listener`.
- Параметр `turn=N` в share-ссылке — партнёр может продолжить с того же вопроса.
- QR-код в блоке «Продолжить сессию» — для продолжения с того же места.
- Плейсхолдер QR-кода до выбора всех опций — не «пустая зона», а понятная подсказка «↑ Выберите колоду, порядок и роль...».
- Кнопка «⏭️ Пропустить» с надписью (раньше была только иконка).
- Счётчик `activeSkippedCount` — только актуальные пропуски (не «перекрытые» последующим ответом).
- Пометки на карточке: «✅ Отвечен ранее» имеет приоритет над «⚠️ Пропущен ранее».
- `hasSavedSession = false` если `isFinished` — завершённая сессия не показывается в блоке «Продолжить».
- Кнопка «↻ Снова» для завершённой сессии — создаёт новую сессию с теми же параметрами.
- Экран завершения без шапки/роли — только «🎉 Сессия завершена!» + кнопки.

### Изменено
- Кнопки под карточкой/подсказкой — палец на телефоне легче достаёт, чем в отдельном footer.
- SetupView: 2 режима (главный экран + форма новой сессии). История сессий — только на главном. «1. Выберите колоду» — только при создании новой.
- Все блоки формы новой сессии видимы сразу с disabled — пользователь видит весь флоу, без сюрпризов и прокрутки.

### Исправлено
- Кнопка «Новая» не сбрасывала активную сессию корректно — `hasSavedSession` был функцией без реактивности. Стал `computed` на основе реактивных refs.
- Баг «вопрос 16 из 15» на экране завершения — `isFinished` теперь корректно вычисляется, шапка/роль скрыты.

## [2.0.0] — 2026-09-17

### Добавлено
- История сессий: массив `coffee_sessions` в localStorage + `coffee_active_session_id`. Можно параллельно вести несколько сессий с разными колодами и возвращаться к ним позже.
- Миграция v1 → v2: старый `game_state` автоматически конвертируется в запись истории при первом открытии.
- Auto-detect `base` через `GITHUB_REPOSITORY` — без привязки к жёсткому имени репо. Работает для любого имени репозитория на GitHub Pages.
- Иконки в manifest относительные — работают на любом поддомене.
- `favicon.ico` добавлен.
- 13 тестов на sessions: создание, переключение, удаление, завершение, миграция v1→v2.

### Исправлено
- Баг с `base` в vite.config.js — был жёстко задан `random-coffee-app`, а реальный репо `random-coffee`. Все ассеты падали с 404. Теперь определяется автоматически.

## [1.0.0] — 2026-09-17

### Добавлено
- Базовая реализация PWA «Random Coffee Cards» на Vue 3 + Vite + Tailwind CSS.
- 2 колоды вопросов: «Глубокие мысли» (15 вопросов) и «Про работу и цели» (10 вопросов).
- 10 предвычисленных порядков (A..J) с детерминированным PRNG — два участника, выбравшие одну букву, получают одинаковую последовательность.
- Выбор роли: «Я читаю первым» / «Я слушаю первым». Чередование после каждого вопроса.
- Сохранение прогресса в localStorage (единственное хранилище).
- Продолжение прерванной сессии.
- Экспорт/импорт состояния в JSON.
- Светлая/тёмная/авто тема с подпиской на системную.
- Анимация переворота карточки, отключаемая при `prefers-reduced-motion`.
- PWA-иконки (192, 512, maskable, apple-touch-icon).
- Service Worker для оффлайн-работы через `vite-plugin-pwa`.
- CI через GitHub Actions (`ci.yml`) — проверка сборки.
- Деплой на GitHub Pages (`deploy-pages.yml`) — автоматическая публикация при пуше в main.
- Vitest-тесты для чистых функций (PRNG, generateOrder) и URL helpers.
