## [5.5.0] — 2026-09-25

### Добавлено
- **Кнопка очистки поиска** — ✕ внутри input справа, видна только при непустом запросе. Клик очищает поле и возвращает фокус. Esc в поле тоже сбрасывает. Hit area ≥ 28×28px для удобного тапа на мобиле.
- **Секция «Доступны для загрузки»** — удалённый каталог больше не спрятан за кнопкой. Сразу под «Загруженными» идёт разделитель и список колод, которых ещё нет на устройстве. Видна только при фильтре «Все» — при «Встроенные»/«Загруженные» пользователь явно хочет только локальное.
- **Авто-загрузка каталога** — при открытии формы новой сессии (первый заход или кнопка «Новая сессия») каталог подгружается автоматически через `ensureCatalogLoaded()`. Идёмпотентно: если уже есть или уже грузится — ничего не делает.
- **Авто-select загруженной колоды** — после `handleLoadFromCatalog` успешная колода сразу выбирается (`selectDeck`), без alert. Пользователь видит её вверху и может сразу выбирать порядок.
- **Дружелюбное сообщение при 404** — `checkDeckUpdates` при HTTP 404 возвращает `{ ok: false, notFound: true, error: 'Колода больше недоступна в каталоге, обновить нельзя. У вас остаётся локальная версия.' }` (вместо сырного `HTTP 404`).
- 13 новых тестов Vitest (всего 127): валидация пустого имени (null, пробелы), тримминг имени, дубликаты `q.id`, откат `importDeck`/`deleteDeck`/`renameDeck` при переполнении localStorage (через `vi.spyOn(Storage.prototype, 'setItem')`), `deleteDeck` активной сессии (confirm + `resetProgress`), `deleteDeck` с отменой, текст confirm-сообщения упоминает «активная», `loadCatalog` применяет дефолт `lang='ru_RU'`, `checkDeckUpdates` HTTP 404 → `notFound: true`.

### Изменено
- **Карточка колоды** — имя перенесено на отдельную строку (`text-lg font-bold`, `line-clamp-2` — всегда видно целиком, до 2 строк). Раньше имя было в одном flex-ряду с бейджем языка и бейджем типа, и `truncate` обрезал длинные имена.
- **Бейджи одного размера** — тип (`Встроенная`/`Загруженная`) и язык (`[RU]`) теперь на одной строке под именем, оба с одинаковым классом `text-[10px] px-2 py-0.5 rounded leading-none border`. Раньше у бейджа типа был `border`, у lang — нет, и высота различалась на 2px.
- **Placeholder поиска** — «Поиск по имени или описанию...» (раньше «Поиск колоды...»).
- **Удалена кнопка «📚 Загрузить из каталога»** — функционал перенесён в секцию «Доступны для загрузки», которая видна всегда (при фильтре «Все»).
- **`saveCustomDecks()`** возвращает `bool`. Раньше возвращал `undefined` и ошибка silently писалась в `console.error` — `customDecks.value` уже был обновлён, после перезагрузки колода пропадала. Теперь `importDeck`/`deleteDeck`/`renameDeck`/`checkDeckUpdates` откатывают изменения в `customDecks.value` при ошибке сохранения.
- **`deleteDeck`** — если удаляется колода активной сессии, confirm показывает дополнительное предупреждение: «Эта колода используется в активной сессии — она будет завершена.» После подтверждения вызывается `resetProgress()` (завершает активную сессию, сбрасывает `activeSessionId`/`deckId`/`orderIndex`/`role`), затем колода удаляется. Без этого фикса `activeSessionId` не сбрасывался, `deck.value` становился null, UI падал при возврате в игру.
- **`validateDeckFormat`** — имя не должно быть пустым или только из пробелов (`deck.name.trim().length > 0`). Раньше `'   '` проходило валидацию, после `slice(0, 128)` получали 128 пробелов — UI показывал «пустую» карточку.
- **`validateDeckFormat`** — вопросы должны иметь уникальные `id`. Раньше `generateOrder` создавал последовательность с дубликатами, `currentQuestion` находил первый попавший — поведение было непредсказуемым.
- **`normalizeDeck`** — имя триммится: `(deck.name || '').trim().slice(0, 128)`.
- **`loadCatalog`** — применяет дефолт `lang='ru_RU'` к элементам без `lang`. Раньше в каталоге бейджа `[RU]` не было, а после загрузки появлялся — визуальная несогласованность.
- **`SetupView.vue`** — удалены `showCatalog`, `catalogSearch`, `toggleCatalog`, `filteredCatalog` (заменён на `filteredRemoteCatalog` + `searchHasNoMatchInRemote`). Добавлены `deckSearchInput` (ref для фокуса после очистки), `ensureCatalogLoaded`, `searchHasNoMatchInRemote` (computed для дружелюбного пустого состояния «Ничего не найдено в каталоге» вместо «Все колоды уже загружены»).
- **`handleLoadFromCatalog`** — тихий успех: вместо `alert('Колода "X" загружена')` вызывается `selectDeck(result.deck.deckId)`. Ошибки всё ещё через alert.
- **`handleCheckUpdates`** — добавлена ветка `result.notFound` для дружелюбного сообщения о 404.

### Удалено
- Кнопка «📚 Загрузить из каталога» — каталог теперь всегда виден в нижней секции (при фильтре «Все»).
- Сворачиваемая панель удалённого каталога (с отдельным поиском `catalogSearch`) — поиск теперь общий для обеих секций.

## [5.4.0] — 2026-09-25

### Добавлено
- **Единый каталог колод** — встроенные и загруженные колоды теперь в одном списке (как extensions в VSCode), а не в трёх раздельных секциях. У каждой колоды — бейдж типа: «Встроенная» (приглушённый) или «Загруженная» (изумрудный, с тонкой рамкой).
- **Поиск и фильтры** в каталоге: строка поиска по имени и описанию + чипы-фильтры «Все / Встроенные / Загруженные» со счётчиками.
- **sourcePath** — новые метаданные происхождения колоды (не показываются в UI, хранятся для диагностики):
  - `'embedded'` — встроенная колода;
  - `'<file.name>'` — импортирована из файла (только имя, без пути);
  - `'/path/in/repo.json'` — загружена из каталога (path из URL без домена, например `/random-coffee-decks/deeps/foo-ru_RU.json`).
- **`catalogDecks`** — новый computed в `useDeck()`: массив `{ ...deck, kind: 'builtin' | 'custom', sourcePath }`, отсортированный — встроенные сверху (по алфавиту имени), затем кастомные (по алфавиту имени).
- **`isCustomDeck(deckId)`** — helper, true если колода принадлежит кастомным (загруженным).
- **`SOURCE_EMBEDDED`** — экспортируемая константа `'embedded'` для sourcePath встроенных колод.
- Кнопки управления кастомной колодой (↓ экспорт, ✕ удалить, 🔄 проверить обновления) теперь прямо на карточке колоды в каталоге. `@click.stop` предотвращает выбор колоды при клике по кнопке.
- В удалённом каталоге колоды, уже загруженные локально, помечаются «✓ загружена» и кнопка «Загрузить» disabled. Список скрывает уже загруженные по умолчанию.
- 11 новых тестов Vitest (всего 114): `catalogDecks` (сортировка, kind, sourcePath), `isCustomDeck`, `importDeck` sourcePath (opts, deckData, приоритет opts, без sourcePath), `loadDeckFromUrl` выводит sourcePath из URL pathname.

### Изменено
- `importDeck(deckData, opts = {})` — опциональный второй аргумент `{ sourcePath }`. Если задан — имеет приоритет над `deckData.sourcePath` (для файла caller знает имя). Если не задан — берётся `deckData.sourcePath` (для бэкапа). Иначе `null`.
- `loadDeckFromUrl(url, opts = {})` — автоматически выводит `sourcePath` из URL: `url.pathname + (url.hash || '')`. Caller может передать свой `sourcePath` в opts.
- `normalizeDeck` — добавлено поле `sourcePath` (по умолчанию `null`).
- `exportDeck` — выгрузка теперь содержит `sourcePath` (для пере-импорта без потери метаданных).
- `SetupView.vue` — три раздельные секции («ГОТОВЫЕ КОЛОДЫ» / «КАТАЛОГ КОЛОД» / «ИМПОРТ ИЗ ФАЙЛА + МОИ КОЛОДЫ») заменены одним единым каталогом. Удалены `showMyDecks`, `availableDecks`, `filteredCatalog` (заменён на `filteredCatalogDecks` + `filteredRemoteCatalog`). Добавлены `deckSearch`, `deckFilter`, `deckFilters`, `filteredCatalogDecks`, `isDeckAlreadyLoaded`, `filteredRemoteCatalog`.
- Удалённая панель каталога теперь показывается под кнопкой «📚 Загрузить из каталога» (а не отдельным блоком). Кнопка переименована «Открыть каталог» → «Загрузить из каталога» (более точное действие).

### Удалено
- Кнопка «📋 Мои колоды» (отдельный список управления) — функционал перенесён в карточки каталога.
- Секция «ГОТОВЫЕ КОЛОДЫ» — объединена с кастомными в единый список.

## [5.0.0] — 2026-09-20

### Добавлено
- **Переименование сессий** — поле `name` в `Session`. В карточке истории — кнопка ✎, при клике появляется inline input под карточкой (с placeholder «Например: с Анной в пятницу»). Введите имя, нажмите ✓ (или Enter) для сохранения, ✕ (или Esc) для отмены. Имя обрезается до 128 символов, пробелы по краям тримятся, пустое имя — сбрасывает в null. Если имя есть — показываем его жирным, а колоду+порядок — мелким шрифтом.
- **Таймер сессии** — в шапке GameView `⏱ MM:SS` (или `H:MM:SS` если больше часа). Пауза при возврате на главный экран (`goBack`), resume при продолжении (`continueSession` / `openSession`). Накопленное время `elapsedMs` сохраняется в Session, переносится при экспорте/импорте.
- **Статистика на экране завершения** — `Отвечено: X | Пропущено: Y | Время: MM:SS | Начали: DD мес., HH:MM`. Просто показать, без кнопки «Поделиться».
- **Функция `renameSession(id, name)`** — переименование сессии в истории.
- **Функция `formatDuration(ms)`** — форматирует миллисекунды в `MM:SS` или `H:MM:SS`.
- **Функции `resumeTimer()` / `pauseTimer()` / `getCurrentElapsedMs()`** — управление таймером сессии.
- 12 новых тестов Vitest (всего 104): `renameSession` (5 кейсов: установка, обрезка до 128, сброс, несуществующий id, trim), `formatDuration` (4 кейса: 0, 65с, 1ч, отрицательное), `startSession` startTime/elapsedMs, `loadSession` восстанавливает name/startTime/elapsedMs, `migrateV1ToV2` сохраняет startTime из updatedAt.

### Изменено
- `Session` schema — добавлены поля `name` (string|null), `startTime` (ISO), `elapsedMs` (number, мс).
- `migrateV1ToV2` — `startTime` берётся из `old.startTime || old.createdAt || old.updatedAt` (для старых v1-сессий без этих полей — `new Date().toISOString()`).
- `exportSession` / `importState` — переносят `name`, `startTime`, `elapsedMs`.
- `persistActiveSession` — сохраняет `name`, `startTime`, `liveElapsedMs` (с учётом времени с момента resume).
- `startSession` — приостанавливает таймер предыдущей активной сессии, устанавливает `startTime = now`, `elapsedMs = 0`, `name = null`, запускает таймер новой.
- `loadSession` — приостанавливает текущий таймер, восстанавливает `name`/`startTime`/`elapsedMs`, запускает таймер если сессия не завершена.
- `resetProgress` — приостанавливает таймер, сбрасывает `sessionName`/`startTime`/`elapsedMs`.

## [4.3.0] — 2026-09-17

### Добавлено
- **Кэш-стратегия `NetworkFirst` для HTML** с таймаутом 3 секунды: при наличии интернета браузер сначала спрашивает сервер, есть ли свежий `index.html`, и берёт его. Если сеть медленная или отсутствует — fallback на кэш SW. Решает проблему «у одного пользователя старая версия, у другого новая» — оба игрока с интернетом получают актуальный HTML, который подключает актуальные ассеты (с хешем в имени файла).
- **`StaleWhileRevalidate` для ассетов** (JS/CSS/иконки): быстро из кэша, в фоне проверяем свежую версию. Имена файлов с хешем — при изменении содержимого URL меняется, кэш-мисс → свежая версия.
- **UI уведомления об обновлении** через `useRegisterSW` (`virtual:pwa-register/vue`): при обнаружении новой версии SW показывается баннер «🔄 Доступна новая версия» с кнопкой «Обновить». `registerType: 'prompt'` — пользователь сам решает, когда перезагрузить, без авто-обновления в середине сессии.
- **Баннер «Готово к оффлайн»** при первом кэшировании SW — пользователь видит, что приложение можно запускать без интернета.
- В `workbox` конфигурации: `runtimeCaching` с двумя стратегиями, `navigateFallback: 'index.html'`, expiration rules (HTML — 7 дней/5 записей, ассеты — 30 дней/60 записей).

### Изменено
- `vite.config.js` — добавлен `workbox.runtimeCaching` с `NetworkFirst` (HTML) и `StaleWhileRevalidate` (ассеты).
- `src/App.vue` — добавлены `useRegisterSW`, баннеры `needRefresh` и `offlineReady`, кнопки «Обновить» и «Позже».
